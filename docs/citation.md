# Citing plexembler

To cite the software itself, name its version (`plexembler --version`, or the
release given to `nextflow run -r`) and its repository,
<https://github.com/js2264/plexembler>.

GitHub's *Cite this repository* button gives the citation in APA and BibTeX,
from `CITATION.cff`.

## The tools it runs

plexembler runs other people's tools: cite those your results come from. Each
run's MultiQC report has a *Methods description* with the tools of that run
and their references; [CITATIONS.md](https://github.com/js2264/plexembler/blob/main/CITATIONS.md)
lists every tool the pipeline can run.
